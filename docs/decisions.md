# Решения владельца продукта

Эти решения дополняют `TOBI_Habit_Master_Specification.md` и являются частью текущей спецификации.

## D1. Отмена выполнения привычки
- Можно отменить любое выполнение за текущий календарный день, а не только последнее.
- Выполнения прошлых календарных дней отменять нельзя.
- Отмена разрешена, только если списание баллов за это выполнение не опустит баланс ниже 0.

## D2. Серия активности
- Если сегодня ещё нет выполнений, серия считается по завершённым дням, включая вчера (не обнуляется из-за незавершённого сегодня).
- Если сегодня выполнена хотя бы одна привычка, сегодняшний день добавляется к серии.
- Серия сбрасывается только после полностью завершённого календарного дня без единого выполнения.

## D3. Изменение дней недели
- Изменение расписания применяется сразу: добавили сегодняшний день — привычка доступна сегодня; убрали — сразу неактивна.
- Прошлая история и статистика не меняются.
- Со следующего календарного дня применяются только изменения баллов и дневного лимита.

## D4. «За неделю»
- Календарная неделя ПН–ВС, не последние 7 дней.
- График строится ПН–ВС; для будущих дней текущей недели значение 0.

## D5. Профиль / Настройки в MVP
- Звук — disabled/placeholder до появления sound design.
- Тактильная отдача — disabled/placeholder до тестовой версии.
- О приложении.
- Версия приложения.
- Других настроек не добавлять.

## D6. Язык
- MVP — только русский язык. Системы локализации нет; другие языки — после MVP.

## D7. Функциональные цвета
Зафиксированы в `theme/colors.ts`:
- success `#4F8A5B` — позитивное/доступное состояние;
- warning `#E6A23C` — предупреждение;
- error `#D95C5C` — ошибка/опасное действие;
- info `#5F7F9F` — информационное состояние.

## D8. TOBI и идентификаторы сборки
- Ассеты TOBI будут добавлены позже; до этого — нейтральные placeholders. TOBI не создаётся в коде.
- Идентификаторы (централизованно в `app.config.ts`, блок `APP_IDENTITY`):
  - App name: `TOBI Habit`
  - slug: `tobi-habit`
  - iOS bundle identifier: `com.tobihabit.app`
  - Android package: `com.tobihabit.app`

## D10. «Посмотреть приветствие» в Профиле
- В Профиле есть постоянная кнопка «Посмотреть приветствие» (дополняет D5).
- Открывает тот же приветственный экран с комнатой TOBI.
- Только просмотр: не сбрасывает `onboardingCompleted`, не создаёт и не меняет данные.
- «Начать» и жест «назад» возвращают в Профиль.

## D11. Экран «Создание задачи» (дизайн-референс владельца)
- Один экран для онбординга (шаг 3 из 3: цель → желание → задача) и для обычного создания из «Задач».
- Онбординг: заголовок «Давай создадим твою задачу!», индикатор «3/3», «Пропустить» (§5). Обычное создание: «Новая задача», без индикатора.
- Название — до 60 символов со счётчиком (ограничение интерфейса), пустое нельзя сохранить.
- Стоимость — целое число ≥ 1 с цифровой клавиатуры, без кнопок «+/−» и без верхнего бизнес-ограничения
  (технически поле принимает до 15 цифр — безопасное целое).
- Повторение — 7 независимых переключателей Пн–Вс, минимум один день. Дневной лимит — под днями, по умолчанию 1.
- Верх экрана — комната TOBI (`welcome_room.webp`, пока нет отдельной сцены) и TOBI (`tobi_habit_create`).
- TOBI показывается на каждом экране с комнатой: готовый рендер, а пока его нет — нейтральная заглушка поверх комнаты.

## D12. Приветственный экран по утверждённому референсу
- Комната на весь экран (`cover`) с мягкими затемнениями сверху и снизу.
- Сверху слева: «Привет!» (белый, крупный) с двумя оранжевыми штрихами и подзаголовок
  «Я ТОБИ — твой напарник в больших и маленьких достижениях.»
- По центру крупный TOBI (`tobi_wave`): ~51% высоты экрана, ноги на ~77% высоты,
  размер и положение считаются от экрана (`features/onboarding/welcomeLayout.ts`); не перекрывает текст и кнопку.
- Снизу «Начать →» и три точки шагов, без кремовой карточки.

## D13. Единая комната TOBI для разделов
- Один файл `assets/backgrounds/tobi_room_shared.webp` (оригинал владельца, без изменений) — шапка экранов
  «Создание цели», «Создание желания», «Создание задачи», «Задачи», «Награды», «Статистика».
- Комната и TOBI — независимые слои (`components/TOBIRoomHeader.tsx`, каркас экрана `components/RoomScreen.tsx`).
- Нет рендера персонажа — показывается только комната (без заглушек).
- Приветственный экран сохраняет свой утверждённый фон.

## D14. Приветствие при каждом холодном запуске
- При каждом холодном запуске сначала показывается приветственный экран TOBI (утверждённый дизайн D12) на 3 секунды,
  без кнопки «Начать» (её место сохраняется, раскладка не меняется), затем автоматический переход через `router.replace`:
  - `onboardingCompleted = false` → онбординг (цель → желание → задача, шаги можно пропускать) → «Задачи»;
  - `onboardingCompleted = true` → «Задачи».
- Источник истины — существующая настройка `onboardingCompleted` в SQLite (`app_settings`), а не наличие привычек.
- Если чтение ещё идёт по истечении 3 секунд — ждём; при ошибке — экран ошибки с повтором, данные не трогаются.
- Возврат из фона и переключение вкладок приветствие не показывают. «Посмотреть приветствие» в Профиле (D10) — с кнопкой.

## D15. Иконки привычек, целей и желаний
- У привычки, цели и желания есть иконка; выбор необязателен (по умолчанию — универсальная иконка типа).
- Выбор: поле «Иконка» первым в формах создания и редактирования → окно «Выбрать иконку» (сетка 3 колонки,
  «Выбрать» применяет, ✕/фон закрывает без изменений).
- Отображение: круглая пастельная иконка слева в карточках «Задач», «Целей», «Желаний», «Архива» и в заголовке экранов деталей.
- В SQLite хранится только id (`habits.icon_id`, `rewards.icon_id`, миграция v2). Старые записи (NULL)
  и неизвестные id показывают иконку по умолчанию.
- Библиотека: TOBI Icon Library v1 — 70 WebP в `assets/icons/webp/` (раньше 5 временных Ionicons; их id
  `sport`, `reading`, `water`, `language`, `sleep` сохранены). Подложки — цвета категорий из манифеста.
  Подключение и замена — `assets/icons/README.md`.

## D16. Комментарий привычки и компактная карточка
- У привычки есть необязательное поле «Комментарий» (до 120 символов) — в формах создания (включая онбординг)
  и редактирования сразу после названия. Пустое поле = нет комментария. Применяется сразу, как название (D3).
- Комментарий не влияет на баллы, расписание, лимит и статистику. SQLite: `habits.comment` (миграция v3),
  у старых привычек NULL.
- Карточка в «Задачах»: иконка · название (до 2 строк) и комментарий (до 2 строк) · квадрат выполнения ·
  баллы · стрелка к деталям. Полоса прогресса убрана.
- Квадрат: выполнено (лимит дня достигнут) — зелёный (`success`) с белой галочкой; иначе — пустой с бежевой
  обводкой. Нажатие — прежнее выполнение (§9); отмена — по-прежнему на экране привычки (D1).
- При лимите больше 1 рядом с баллами виден прогресс дня, например «1/3» (§8).
- Серия по отдельной привычке не показывается: правила для неё нет (решение владельца — пока не показывать).

## D9. Принятые технические решения
- Удаление привычки — soft delete (`deleted_at`); выполнения и транзакции остаются.
- Баланс не кэшируется: вычисляется как сумма `point_transactions`.
- Иконки: Ionicons, только outline-варианты.
- Дни недели хранятся битовой маской (бит 0 = ПН).

## Технические уточнения реализации (не меняют продуктовую логику)
- Привычка должна иметь хотя бы один выбранный день недели; название и название награды не могут быть пустыми.
- Баллы, лимит и стоимость — целые числа ≥ 1.
- График статистики ПН–ВС показывает количество выполненных действий за день.
- «Заработано баллов» = сумма баллов неотменённых выполнений (траты на награды её не уменьшают).
- Отмена выполнения доступна на экране привычки (список сегодняшних выполнений).
- Изменение баллов/лимита, сделанное сегодня, ставится в pending и вступает в силу с 00:00 следующего дня; на экране привычки показывается «с завтра».
