# Решения по открытым вопросам

Вопросы, которые спецификация не закрывает. Решения принимает владелец продукта.

## Ожидают решения
1. Отмена выполнения: какое выполнение отменяется (последнее за сегодня?) и можно ли отменять выполнения прошлых дней.
2. Серия: если сегодня ещё нет выполнений — показывать серию до вчерашнего дня включительно или 0.
3. Изменение дней недели: вступает в силу сразу (сегодня) или со следующего дня, как баллы/лимит.
4. Статистика «за неделю» и график: календарная неделя ПН–ВС или последние 7 дней.
5. Пункты профиля «Настройки» в MVP (кроме звука/haptic, которые после тестовой версии).
6. Язык интерфейса: только русский?
7. Функциональные цвета success/warning/error/info (сейчас временные значения в `theme/colors.ts`).
8. TOBI-ассеты: до их появления используется нейтральная заглушка.

## Технические решения (в рамках спецификации)
- Удаление привычки — soft delete (`deleted_at`), выполнения и транзакции остаются.
- Баланс не кэшируется: считается как сумма `point_transactions`.
- Дни недели хранятся битовой маской (бит 0 = ПН).
- Иконки: Ionicons, только outline-варианты (единый rounded outline стиль).
