# Music fragments

Put **licensed** audio fragments here (files you have the right to use). Nothing
is downloaded automatically.

Each video has a cue file, e.g. `music_1990_2000.cues.json`: artist, track, start
and end time in the video, the expected file name, an `offset` inside the file
and `gain_db` (music sits under the voice). A cue whose file is missing is
skipped and its slot stays silent.
